# Раскрытие ИИ — Project SIREN · SQUARE TEAM (Астана)

GenAI Jam 2026. ИИ использован во всех четырёх слоях.

| Слой | Инструмент ИИ | Что сделал ИИ | Доля ИИ |
|---|---|---|---|
| Код | Claude Code (Anthropic) | Весь код игры: 2.5D-рендер на Canvas поверх Phaser 3, 3D-станки на Three.js, все механики, интерфейс, сохранения, настройки, оптимизация, звуковой синтез, разметка музыки | ~100 % |
| 2D / 3D-графика | Claude Code + Blender (через Blender MCP), ChatGPT | 3D-модели станков — Python-скрипты для Blender, написанные и запущенные ИИ. Вся 2D-графика (рыыбчеллы, русалка, руки, предметы, иконки, UI) нарисована кодом. Постер «русалка → женщина» — ChatGPT | ~95 % |
| Аудио | Suno, Claude Code | 4 музыкальных слоя под настроение (Calm / Joy / Sad / Rage) — Suno. Звуковые эффекты синтезируются кодом в реальном времени | 100 % |
| Видео и нарратив | Claude Code | Тексты обучения, подсказок, целей, справки и концовок — по дизайн-документу команды | ~70 % |

## Код
- **Инструмент:** Claude Code (Anthropic).
- **Что написано ИИ:** весь код игры (`source/parts`, собирается в `index.html`). Сюда входят:
  - рендер от первого лица;
  - инкубатор, пресс, поведение рыыбчеллов (страх, стаи, память);
  - бонус-серия, настроение и хотелки, ярость;
  - престиж и три концовки;
  - терминал-магазин, обучение по этапам, цели смены;
  - сохранения и настройки.

  Анализ темпа и долей музыки для бесшовных петель тоже сделал ИИ: скрипты на ffmpeg и numpy в `source/tools`.
- **Что сделала команда:** дизайн-документ и задания на каждую итерацию, плейтест каждой сборки, отчёты об ошибках со скриншотами, решения по балансу и UX.
- **Не ИИ:** библиотеки Phaser 3.80 и Three.js r147 (лицензия MIT).

## 2D и 3D-графика
- **3D-модели станков** (инкубатор, пресс, терминал, утилизатор, воронка): ИИ написал Python-скрипты для Blender 4.3 и выполнил их через Blender MCP, затем экспортировал в GLB. Исходники — в `source/blender`. Ручного моделлинга нет.
- **2D:** рыыбчеллы, русалка, руки-перчатки, котлеты, предметы, иконки и весь интерфейс рисуются процедурно на Canvas. Этот код написал Claude Code.
- **Постер «план-схема: русалка → женщина»** (главное меню и стена лаборатории) сгенерирован в ChatGPT (OpenAI) по запросу команды и вставлен без доработки.
- **Не ИИ:** логотип SQUARE TEAM сделала команда. Шрифты Nunito и Russo One взяты из Google Fonts (SIL OFL).

## Аудио
- **Музыка:** 4 трека-слоя сгенерированы в Suno на бесплатном тарифе. Промпт составлен вместе с Claude по заданию команды. Слои переключаются по настроению русалки и синхронизируются по тактам — это код Claude Code.
- **Звуковые эффекты:** синтезируются в реальном времени через WebAudio. Код написал Claude Code, записанных сэмплов нет.

## Видео и нарратив
- **Команда:** идея, сеттинг, персонажи и три концовки — из дизайн-документа команды.
- **ИИ:** тексты в игре (обучение, подсказки, цели, справка, тексты концовок) написаны Claude Code по этому документу. Команда их проверила.
- **Видео геймплея:** запись реальной игры без монтажа, без ИИ.

## Права
- Условия Claude (Anthropic) и ChatGPT (OpenAI) разрешают коммерческое использование результатов.
- **Suno: треки сделаны на бесплатном тарифе.** Он разрешает только некоммерческое использование. Для показа на джеме это подходит. До коммерческого релиза музыку перегенерируем на платном тарифе или заменим.
- Phaser и Three.js распространяются по лицензии MIT, шрифты — по SIL OFL. Чужой интеллектуальной собственности и готовых наборов ассетов в игре нет.
